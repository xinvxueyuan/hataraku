# UI/UX 评审（oil-ui 方法）— 2026-10-21

审查对象：https://www.xinvstar.xyz 线上版。取证：`artifacts/review-oil/`（home/article 的 1440+390、post、docs、search、空结果、移动端长文）。
工具：`oil_ui_shoot`（含 DOM 提示与对比度告警），并用 Playwright 独立复算对比度。
方法：两条轨道 —— **A 视觉层级与工艺** / **B 可用性与任务流**。

## A 视觉层级与工艺

**A1 首页首屏没有视觉主角。** 标题 + 两行文案之后直接进卡片流；"夜行栈"这个意象没有任何视觉表达。首屏最贵的位置给了三行字，可替代性很高 —— 换个站点名与配色就是一个通用博客首页。
（这一条涉及设计方向，需要先定方向再改，见文末建议。）

**A2 封面占位符读起来像坏图。** 大灰框里放一个字符：`—`、`年`、`一`、`深`、`N`、`C`。其中 `一`（U+4E00）与破折号在视觉上无法区分，用户第一反应是"图片没加载"。
**A3 文章详情页有两个内容相同的 `<h1>`。** 实测 HTML：`h1` 数量 = 2，文本完全一致（页头标题 + 正文首个 `#` 标题）。视觉上标题出现两次，语义上破坏文档大纲。
**A4 首页与 /article 的层级不一致。** `/article` 有 lead 项（24px/600），首页六张齐平（16px/500）；且 h1 36px 与区块标题 20px、卡片标题 20px 过近，层级靠字号单薄地撑。
**A5 长文没有阅读导航。** 该文 6760px、9 个 `h2`，页面无目录（实测无 `aria-label="本页目录"`），无阅读进度。
**A6 文档页表格表头与正文同级。** 能力/来源/备注 与数据行同字重，仅一条发丝线分隔，扫读定位困难。
**A7 四种容器提示的垂直节奏不一致。** note 与 tip 的正文起点不同，成组出现时显得随手。

## B 可用性与任务流

**B1（已撤回，见文末更正）** 曾报「浅色主题 `更多` 下拉 2.68:1」。**该结论错误** —— 用真实 UI 切换主题后实测 **6.02:1**，全部达标。
**B3 搜索结果上下文弱于文章列表。** 无分类/标签、结果标题同字号，没有排序或类型信号。
**B4 长文无法定位（与 A5 同源）。** 读 6700px 长文时无法跳章节、无回到顶部。
**B5 分页禁用态仍像可点。** `/article` 第 1 页的"上一页"有 aria-disabled + opacity，但视觉上仍是一段可点文本。
**B6 发现路径单一。** 首页除"全部文章"外只有分类 chips；归档/分类与标签/相册/工具箱都藏在 `更多` 里。

## 通过项（不要改坏）

- 深色主题正文对比度 7.2:1、标题 17.2:1，远超 AA；浅色正文 5.86:1。
- 搜索命中高亮有效（`Goo` → 标题/摘要/片段均高亮），正文片段已能说明"为什么这条被搜到"。
- 文档站三栏结构（分组侧栏 + 正文 + 本页目录）、四种容器、代码复制、上/下一篇齐备。
- 移动端抽屉四条关闭路径、导航完整（11 项）。
- 主题按钮有 `aria-label="Toggle theme"`。

## 更正记录（2026-10-21 晚）

**B1 是误报，撤回。** 我最初的测法是在脚本里直接 `localStorage.setItem('theme','light')` + `classList.remove('dark')` 后**同步测量**，此时面板已按浅色重绘、但文字仍读到**深色主题的 `--muted-foreground`（oklab 0.70）**，于是算出 2.68:1 —— 正好等于深色令牌放白底的值（0.70 → 2.67）。

**正确测法**（我随后复测）：走真实 UI 切主题 → 等重绘 → 确认 `classList` 无 `dark`、`--muted-foreground` 为浅色令牌 `lab(41.889% …)` → 再测。结果：

```
更多 下拉四项  6.02:1   ✓
--muted-foreground (light) = lab(41.889% .0782758 -7.48051)
```

auth 独立复测全线通过：浅色 正文 17.24 / 标题 17.30 / 二级 5.86 / 标签 13.83 / 占位 17.76 / muted 面 5.38 / accent 面 5.26；深色无回退。唯一低于 4.5 的是 `disabled:opacity-50`，WCAG 1.4.3 明确豁免非活动控件。

教训：**主题/令牌这类跨层状态，必须等渲染稳定并读令牌值确认状态，再测颜色** —— 同一族错误我今天犯了第二次（前一次是 React state 未重渲染就同步读 DOM）。
