## 发布前

先跑完整门禁，确保类型、lint、测试与构建都在同一棵树上通过。

```bash
pnpm run ready
```

:::warning 不要在红树上发布
门禁失败时先修代码，不要用跳过测试的方式换取一次「看起来成功」的发布。
:::

## 构建

Web 与 API 一起构建，产物由平台托管：

```bash
pnpm run build
```

### 环境变量

生产环境需要数据库连接、认证密钥与对象存储配置。密钥只放在部署平台的环境变量里，不进入仓库。

## 发布后

- 打开首页与 `/docs`，确认渲染与导航正常；
- 看一次服务端日志，确认没有 5xx；
- 记录版本号与时间，方便回滚时对照。
